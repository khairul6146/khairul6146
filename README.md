### 👋 Welcome to My Digital Workshop

I treat software engineering as a continuous craft. This GitHub profile is my personal laboratory—a space where I build practical tools to solve everyday frictions, experiment with emerging technologies, and learn by shipping working software.

> *"The best way to understand how something works is to build it yourself."*

- 💡 **Build to Solve:** I create tools for real personal use-cases (automated receipt parsing, offline OCR notes, finance calculators, and event dashboards).
- 🧪 **Hands-on Experimentation:** Testing new architectural patterns across the modern web (Next.js 15, FastAPI, Tailwind CSS, and local AI agent workflows).
- ⚙️ **Practical Automation:** Writing shell scripts, background automations, and desktop utilities that remove repetitive daily friction.

---

### 🧪 Currently In The Lab / What I'm Learning

Here are the concepts and technologies I'm actively exploring right now:

- 🚀 **Modern Web Architecture:** Deep-diving into **Next.js 15**, React 19 Server Components, streaming UI, and tactile UI design with **Tailwind CSS & shadcn/ui**.
- ⚡ **Asynchronous Backends:** Crafting blazingly fast Python REST microservices using **FastAPI**, Pydantic v2, and SQLite/PostgreSQL.
- 🤖 **Agentic & AI Tooling:** Experimenting with local agent harnesses, context memory pipelines, and tool-augmented workflows.
- 💻 **Windows & Shell Automation:** Harnessing **PowerShell 7+** and WinRT native APIs for offline-first desktop tools.
